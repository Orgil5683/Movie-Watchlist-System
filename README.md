# Movie-Watchlist-System
Movie Watchlist System (Кино жагсаалтын систем)

Кино үнэлгээгээ хадгалж, харах боломжтой терминал дээр ажилладаг программ. Кино нэмэх, устгах, жагсаалтаа харах, дундаж үнэлгээгээ харах боломжтой бөгөөд бүх өөрчлөлт файлд хадгалагдана.

Боломжууд
Бүх киногоо дугаарлагдсан байдлаар харах
Шинэ кино нэмэх (нэр, төрөл, үнэлгээ), давхардсан нэр орохоос сэргийлнэ
Кино нэрээр нь устгах
Бүх кино дээрх дундаж үнэлгээг харах
Өөрчлөлтөө movies.txt файлд хадгалах

Өгөгдлийн формат
movies.txt дахь мөр бүр нэг кино: нэр,төрөл,үнэлгээ

Цаашид нэмж болох зүйлс
Кино төрлөөр шүүх
Үнэлгээгээр эрэмбэлэх
Үнэлгээгээг шинэчилэх
"Үзсэн" ба "Үзэхийг хүсэж буй" гэж тусад нь хадгалах
